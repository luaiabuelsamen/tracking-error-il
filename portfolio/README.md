# Robot field notes

Portable portfolio gallery: `index.html`, `gallery.js`, and `media/`.
Open `index.html` in a browser; no build tools or backend are required.
Upload the entire folder to your static website when ready. Nothing is published automatically.

After recording a showcase, refresh from the repository root:

    python scripts/update_portfolio.py

Only showcase MP4s, a labelled teleoperation clip and a labelled simulation clip
are included. The update copies the current paper. Showcase clips are unannotated;
review them before publishing and describe their actual outcomes. Numerical
hardware results are from the existing study, not the showcase recordings.
